# Void Play — Telegram Web App (фронтенд)

Визуал по макету из Figma на чистых HTML/CSS/JS, без сборщиков. Бэкенда пока нет: все данные — моки в `js/api.js`.

## Запуск

```bash
cd voidplay
python3 -m http.server 8080
# открыть http://localhost:8080
```

В Telegram: хостишь папку на любом статическом хостинге с HTTPS (Vercel, Netlify, GitHub Pages) и указываешь URL в @BotFather → Bot Settings → Menu Button / Web App.

## Структура

```
index.html          каркас + экран загрузки
css/style.css       все стили (токены цветов в :root)
js/config.js        ссылки на канал, поддержку, бота, интервалы — правь тут
js/i18n.js          тексты RU / EN
js/api.js           данные (моки) — сюда потом подключается бэкенд
js/ui.js            тосты, шторки, модалки, звук, хаптика
js/sheets.js        пополнение/вывод, настройки, подписка, «добавить подарок», выбор NFT, уровни, промокод
js/router.js        роутинг по #/home, #/upgrader, #/profile, #/referrals, #/tasks, #/leaders
js/screens/*.js     экраны
assets/img/         картинки из Figma (см. ниже)
```

## Что сделано

- **Загрузка**: логотип, «Welcome 2 Void Play», прогресс-бар (реально предзагружает картинки).
- **Главная**: баланс (тап — пополнение), настройки, аватар → профиль, Connect, LIVE-лента выигрышей (новые въезжают слева), карусель бонусов (каждые 30 c заполняется полоска и листает вправо, свайп, тап по полоске), промокод, сетка 8 игр (Апгрейдер открывается, остальные — «Скоро»).
- **Подписка на канал**: модалка при каждом входе, пока не подписан; крестик заполняется 3 c и только потом закрывает; «Забрать» → канал → проверка → +15 Stars.
- **Апгрейдер**: ставка звёздами (−10 / +50 / MAX) или подарком, цель из каталога (поиск, «Показать ещё» → шторка), кольцо шанса со стрелкой и анимацией, «ПРОКАЧАТЬ», тосты выиграл/проиграл/недостаточно stars. «Добавить подарок» показывается при каждом входе и по кнопке «?».
- **Тосты**: справа сверху, въезжают и улетают вправо, полоска (зелёная/красная) убывает за 3 c.
- **Пополнение / вывод**: табы, баланс, сумма, выгодные пакеты, кнопки TON (+N%) / Stars / $ с пересчётом по курсу.
- **Профиль**: аватар и имя из Telegram, статус, кошелёк, инвентарь (или «Пусто»), «Показать все», «Пополнить подарки», служба поддержки, рефералка (поделиться / подробнее), история транзакций, баннер заданий.
- **Друзья (рефералы)**, **уровни** (шторка), **задания** (В процессе / Забрать / Сделано), **лидеры**, **настройки** (звук, громкость, язык RU/EN, соглашение, поддержка).

## Что подключить на бэкенде (aiogram)

Каждая функция в `js/api.js` помечена — её заменяешь на запрос к своему API. Пользователя на сервере проверяй по `Telegram.WebApp.initData` (подпись HMAC с токеном бота).

- **Подписка на канал**: `bot.get_chat_member(channel_id, user_id)`; бот должен быть админом канала.
- **Пополнение Stars**: `bot.create_invoice_link(currency="XTR", ...)` → на фронте `Telegram.WebApp.openInvoice(link)`.
- **TON**: кошелёк подключается через TON Connect, входящие платежи проверяются через TON Center API (по комментарию с id юзера), сумма конвертируется в звёзды по вашему курсу.
- **$**: CryptoBot (Crypto Pay API) → тоже конвертируется в звёзды.
- **Подарки**: принимает бизнес-аккаунт @voidplay (Business API: `get_business_account_gifts`), бэкенд кладёт их в инвентарь юзера.
- **Апгрейдер**: шанс и результат считаются **только на сервере**. Сейчас формула-мок: `ставка / цена цели × 0.9`, максимум 75%.
