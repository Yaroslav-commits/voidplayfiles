# Void Play — сайт (Telegram Web App)

Чистый HTML/CSS/JS без сборки — лежит на GitHub Pages и открывается кнопкой «Играть» в боте.

```
index.html      каркас и экран загрузки
config.js       ← НАСТРОЙКИ: адрес API бота, название, ссылки
css/app.css     весь дизайн
js/core.js      тексты RU/EN, иконки, связь с API, шторки, эффекты
js/screens.js   экраны: Игры, Апгрейдер, Мины, Топ, Бонусы, Профиль, Друзья
js/app.js       меню, шапка, загрузка, переподключение
img/gifts       подарки (имя файла = id в каталоге бота)
img/games       обложки игр
img/deco        3D-картинки для баннеров
```

## Связь с ботом на bothost
1. В панели bothost включи домен для бота и проверь в браузере: `https://<домен>/api/health` → `"ok": true`.
2. Впиши домен в `config.js` → `API_BASE`.
3. В `.env` бота: `WEBAPP_URL` = адрес этого сайта, `ALLOWED_ORIGINS` = `https://yaroslav-commits.github.io`.

Сайт сам повторяет запросы при сбоях, показывает плашку «Связь потеряна» и переподключается.
Если сервер не ответил при входе — экран «Нет связи» с кнопкой «Повторить».

### Проверка без Telegram
- Просто открыть сайт в браузере — демо-режим (фейковый баланс, ничего не сохраняется).
- `?api=https://другой-домен` — временно сменить адрес API (запоминается; `?api=reset` — сбросить).
- `?dev=42` — войти игроком 42 (только если бот запущен с `DEV_MODE=1`, для локальных тестов).

## Смена названия
`APP_NAME` в `config.js` (сайт) и `APP_NAME` в `.env` бота.

## Новый подарок
Положи `img/gifts/<id>.webp` и добавь id в `GIFT_FILES` в `js/core.js`, а сам подарок — в `GIFTS` в `config.py` бота.
Подарки без картинки показываются цветной коробкой.
